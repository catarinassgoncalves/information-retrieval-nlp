# Information Retrieval & Text Summarization

Information retrieval and text summarization system combining **lexical retrieval, dense semantic representations, supervised learning, clustering, and language models**.

The project explores multiple approaches to extractive and abstractive summarization, including **BM25, Sentence Transformers, MMR, supervised sentence ranking, T5 fine-tuning, and clustering-based summarization**, with a focus on comparing lexical, semantic, and learned representations.

## Project Overview

The project was developed in two stages:

1. **Unsupervised Information Retrieval** — implementation and comparison of lexical and semantic approaches for keyword extraction and extractive summarization.
2. **Supervised & Clustering-based Information Retrieval** — incorporation of reference summaries through supervised learning and T5 fine-tuning, together with an alternative clustering-based summarization strategy.

Experiments were conducted on the **BBC News dataset**, containing articles from multiple news categories.

---

## 1. Unsupervised Information Retrieval

The first stage explored different representations and retrieval strategies for identifying relevant sentences and keywords.

### Extractive Summarization

Three main retrieval approaches were compared:

- **BM25** — lexical relevance based on term frequency and document statistics.
- **MiniLM** — semantic retrieval using dense sentence embeddings.
- **BAAI BGE** — alternative dense embedding representation.

The semantic models substantially outperformed the lexical BM25 baseline.

| Model | Macro Fβ | Average Precision |
|---|---:|---:|
| BM25 | 0.3663 | 0.2729 |
| BAAI BGE | 0.4834 | 0.3940 |
| **MiniLM** | **0.5321** | **0.4570** |

The results show the advantage of dense semantic representations for identifying summary-relevant sentences, with **MiniLM achieving the strongest overall performance**.

### Keyword Extraction

Traditional **TF-IDF keyword extraction** was compared with keywords generated by small language models.

Although the LLM-generated keywords had low exact lexical agreement with TF-IDF, their semantic similarity was considerably higher:

| Model | Lexical Agreement | Semantic Similarity |
|---|---:|---:|
| TinyLlama | 9.89% | 58.72% |
| Qwen | 8.14% | 60.88% |

This suggests that the language models often identify **semantically related concepts using different wording**, which is not captured by exact lexical matching.

## 2. Supervised Information Retrieval

The second stage investigated whether reference summaries could provide useful supervision for the summarization system.

The dataset was divided using an **80/20 stratified train-test split**, corresponding to 1,780 training documents and 445 test documents.

Two complementary approaches were explored:

- Fine-tuning a pretrained sequence-to-sequence model for abstractive summarization.
- Reformulating extractive summarization as a supervised sentence-ranking problem.

### T5 Fine-Tuning

A pretrained **T5-small** model was fine-tuned on the BBC News reference summaries.

The model was trained for 5 epochs using a learning rate of `5e-5`, selected based on validation ROUGE-L performance.

Fine-tuning produced a substantial improvement over the pretrained baseline:

| Model | ROUGE-1 | ROUGE-2 | ROUGE-L |
|---|---:|---:|---:|
| Base T5-small | 0.3205 | 0.2110 | 0.2339 |
| **Fine-tuned T5-small** | **0.5197** | **0.3904** | **0.3857** |

The results demonstrate that adapting T5 to the target news domain substantially improves alignment with the reference summaries.

### Supervised Sentence Ranking

Extractive summarization was also formulated as a sentence classification and ranking problem.

Each sentence was represented using four features:

- Sentence length
- Relative position in the document
- TF-IDF relevance
- Semantic similarity between the sentence and document embeddings

Training labels were generated through **ROUGE-2 matching** against the reference summaries.

Two classifiers were evaluated:

| Model | Precision | Recall | F1 | AUC |
|---|---:|---:|---:|---:|
| Random Forest | 0.5721 | 0.2576 | 0.3552 | **0.8253** |
| Naive Bayes | 0.3965 | **0.4031** | **0.3998** | 0.8188 |

For final summarization, sentence probabilities were used to rank candidates rather than relying directly on the binary classification threshold.

### Comparison with Unsupervised Methods

The supervised approaches were evaluated against the unsupervised methods from the first stage on the same holdout test set.

| Model | Macro Fβ | ROUGE-1 | ROUGE-2 | ROUGE-L |
|---|---:|---:|---:|---:|
| BM25 | 0.3426 | 0.5674 | 0.4407 | 0.3994 |
| **MiniLM** | **0.5319** | **0.6245** | **0.5362** | **0.4294** |
| Random Forest | 0.4243 | 0.6045 | 0.4848 | 0.4159 |
| Naive Bayes | 0.3901 | 0.6142 | 0.4948 | 0.4212 |

The supervised models improved over the lexical BM25 baseline but did not surpass **MiniLM**, indicating that strong pretrained semantic representations remained highly effective for this task.

## 3. Clustering-Based Summarization

An alternative unsupervised summarization strategy was developed using **Hierarchical Agglomerative Clustering (HAC)** over Sentence Transformer embeddings.

The pipeline:

1. Encodes document sentences into dense vectors.
2. Groups semantically related sentences using hierarchical clustering.
3. Selects the number of clusters using the **Silhouette score**.
4. Computes each cluster centroid.
5. Selects the sentence closest to each centroid as its representative.
6. Restores the selected sentences to their original document order.

This encourages the summary to cover different semantic regions of the document rather than repeatedly selecting highly similar sentences.

### Results

| Model | Macro Fβ | ROUGE-1 | ROUGE-2 | ROUGE-L |
|---|---:|---:|---:|---:|
| BM25 | 0.3435 | 0.5708 | 0.4446 | 0.3975 |
| **MiniLM** | **0.5330** | **0.6369** | **0.5504** | **0.4408** |
| MMR | 0.3203 | 0.4885 | 0.3453 | 0.3382 |
| Clustering | 0.2982 | 0.4412 | 0.3098 | 0.3169 |

Clustering achieved lower ROUGE-based performance than direct semantic retrieval, but produced considerably more concise summaries.

| Model | Avg. Summary Length | Execution Time |
|---|---:|---:|
| BM25 | 124.9 | 417.15 s |
| MiniLM | 109.6 | **18.21 s** |
| MMR | 96.9 | 125.74 s |
| **Clustering** | **84.2** | 50.70 s |

This illustrates a trade-off between **reference-summary overlap and semantic diversity**: clustering generated shorter and more diverse summaries, while MiniLM remained the strongest approach according to the evaluation metrics.

---

## Key Findings

- Dense **Sentence Transformer embeddings** substantially outperformed lexical BM25 retrieval for extractive summarization.
- **MiniLM** provided the strongest extractive summarization results across the evaluated approaches.
- Fine-tuning **T5-small** substantially improved abstractive summarization over the pretrained model, increasing ROUGE-1 from **0.3205 to 0.5197**.
- Supervised sentence ranking improved over the lexical baseline but did not outperform direct semantic retrieval with MiniLM.
- LLM-generated keywords showed low lexical overlap with TF-IDF but considerably stronger **semantic agreement**.
- Hierarchical clustering produced the **most concise summaries**, illustrating the trade-off between semantic coverage/diversity and ROUGE-based performance.
